# English

## kube-accelerator-sim v0.7.3

v0.7.3 makes Hygon DCU telemetry discoverable by the existing
`accelerator-exporter` `hygon-dcu` rule.

- The chart adds a `<release>-dcu-exporter` Service. Its labels are `app.kubernetes.io/name=dcu-support` and `app.kubernetes.io/component=exporter`, and its port name is `metrics`. It selects the existing centralized telemetry Pod and does not start an exporter on a Synthetic Node.
- The Hygon contract now includes `dcu_powercap`, set to the profile power limit. The Telemetry Catalog revision is `2026-11-23.2`, digest `sha256:f9c7e16e9233e38ada87498a34e29bacf7500d6050a79e296702b7d6b4736496`.
- Docker: `ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.3`. Helm chart: `kasim-runtime` `0.7.3`. The published `0.7.2` tag is unchanged.
