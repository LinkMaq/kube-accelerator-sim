# 中文

## kube-accelerator-sim v0.7.2

v0.7.2 增加海光 BW100 整卡型号，并为 BW100 与 BW1100 补上 DCU Exporter 使用的产品名。

### 主要变化

- `hygon` 增加可选型号 `hygon-bw100`，整卡资源仍是 `hygon.com/dcu`。型号身份来自
  Rune 公布的驱动兼容表（grade B），该表把它与 BW1000、BW1100、BW150、BW10 列在一起，
  并注明整理自海光开发部署指南。2026-07-31 的光合文档索引检查没有列出 BW100。
- `hygon-bw100` 与 `hygon-bw1100` 把平台型号标签
  `feature.node.cloud.xiaoshiai.cn/accelerator-model.name` 写成 `bw100` 与
  `bw1100`。其它型号仍使用目录 ID。
- 海光遥测的 `name` 标签改为产品名：`K100_AI`、`BW100`、`BW1100`。显存继续使用
  既有 32GiB 默认包络，不为 BW100 / BW1100 填写没有厂商原文的容量。
- Profile Catalog revision 升级为 `2026-11-23.1`，摘要
  `sha256:6ad9dcc1ff6639b95d7c56474fe3e01264dafde447c496e41172b58c09927735`。
  Telemetry Catalog revision 升级为 `2026-11-23.1`，摘要
  `sha256:140d9f39e644fc3fa533ffdaf24e42c144bb4cb358161eae0fed0f41570b409d`。
- 新增单节点 8 卡示例 `examples/hygon-bw100.yaml`。

### 升级说明

该版本不更改 Scenario CRD、整卡资源名或 Kubernetes 支持范围；仍支持 Kubernetes
1.30–1.36。

目录 revision 变化意味着既有场景实例不可原地升级。升级 runtime 前先删除既有场景
实例，再用新 CLI 重新提交。

### 发布产物

- Docker：`ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.2`。
- Helm Chart：`kasim-runtime` `0.7.2`。已发布的 `0.7.1` 标签保持不变。

# English

## kube-accelerator-sim v0.7.2

v0.7.2 adds the Hygon BW100 whole-card model and records the DCU Exporter
product names for BW100 and BW1100.

### Changes

- `hygon` gains the selectable model `hygon-bw100`. The whole-card resource
  remains `hygon.com/dcu`. The model identity comes from Rune's published driver
  compatibility table (grade B), which lists it with BW1000, BW1100, BW150, and
  BW10 and attributes that list to Hygon's developer deployment guide. The
  2026-07-31 sourcefind index check did not list BW100.
- `hygon-bw100` and `hygon-bw1100` project
  `feature.node.cloud.xiaoshiai.cn/accelerator-model.name` as `bw100` and
  `bw1100`. Other models keep their catalog IDs.
- The Hygon telemetry `name` label now uses the product name: `K100_AI`,
  `BW100`, and `BW1100`. Memory stays on the existing 32GiB default envelope.
- The Profile Catalog revision advances to `2026-11-23.1`, digest
  `sha256:6ad9dcc1ff6639b95d7c56474fe3e01264dafde447c496e41172b58c09927735`.
  The Telemetry Catalog revision advances to `2026-11-23.1`, digest
  `sha256:140d9f39e644fc3fa533ffdaf24e42c144bb4cb358161eae0fed0f41570b409d`.
- `examples/hygon-bw100.yaml` projects one node with eight BW100 cards.

### Upgrade

This version does not change the Scenario CRD, the whole-card resource name, or
the Kubernetes range. Kubernetes 1.30–1.36 remains supported.

A catalog revision change means existing Scenario Instances cannot be upgraded
in place. Delete them before upgrading the runtime, then submit them again with
the new CLI.

### Artifacts

- Docker: `ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.2`.
- Helm chart: `kasim-runtime` `0.7.2`. The published `0.7.1` tag is unchanged.
