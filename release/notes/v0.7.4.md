## kube-accelerator-sim v0.7.4

v0.7.4 增加一台可调度的海光 BW100 预切分 vDCU 节点。

- BW100 可以选择已有证据的 `hygon.com/dcu-share-30c-16g`。示例是 `examples/hygon-bw100-vdcu.yaml`，一台节点 8 个该规格的 vDCU，不登记整卡 `hygon.com/dcu`。
- 这种资源的遥测改发 `vdcu_utilizationrate` 和 `vdcu_usedmemory_bytes`，标签含 `vdcu_minor_number`、`vdcu_computer_unit` 和 `vdcu_memory_cap`。
- Profile Catalog 修订为 `2026-11-23.2`，摘要 `sha256:2acfb1b7c0afd7d7543b165b7c58bd1c0a87321ac15d057b071ac3194f57e79f`。海光档案摘要 `sha256:5b24b58ee01c21e9ae57cdc8eb72eb1e910db98e23c468cfb89cbe3a645eec73`。
- Docker：`ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.4`。Helm Chart：`kasim-runtime` `0.7.4`。已发布的 `0.7.3` 标签保持不变。

# English

## kube-accelerator-sim v0.7.4

v0.7.4 adds a schedulable pre-split Hygon BW100 vDCU node.

- BW100 can select the evidenced `hygon.com/dcu-share-30c-16g` profile. `examples/hygon-bw100-vdcu.yaml` projects one node with eight of those vDCUs and does not register whole-card `hygon.com/dcu`.
- Telemetry for that resource emits `vdcu_utilizationrate` and `vdcu_usedmemory_bytes`, labeled with `vdcu_minor_number`, `vdcu_computer_unit`, and `vdcu_memory_cap`.
- The Profile Catalog revision is `2026-11-23.2`, digest `sha256:2acfb1b7c0afd7d7543b165b7c58bd1c0a87321ac15d057b071ac3194f57e79f`. The Hygon profile digest is `sha256:5b24b58ee01c21e9ae57cdc8eb72eb1e910db98e23c468cfb89cbe3a645eec73`.
- Docker: `ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.4`. Helm chart: `kasim-runtime` `0.7.4`. The published `0.7.3` tag is unchanged.
