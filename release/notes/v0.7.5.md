# 中文

## kube-accelerator-sim v0.7.5

v0.7.5 增加一台可调度的天数 MRC-V100 物理节点。

- 示例是 `examples/iluvatar-mrc-v100.yaml`：一台节点 8 个芯片，资源 `iluvatar.com/gpu`。运行时写入 `feature.node.cloud.xiaoshiai.cn/accelerator-model.name=mrc-v100`。
- 遥测按 IX Exporter 4.3.0 发布 `ix_gpu_utilization`、`ix_mem_total`、`ix_mem_used`、`ix_mem_free`、`ix_mem_utilization`、`ix_temperature`、`ix_power_usage`，以及健康时为 0 的 `ix_ecc_sbe_vol_status` 和 `ix_ecc_dbe_vol_status`。`name` 使用驱动名 `MRC-V100-0x1B`。显存沿用档案默认 32768 MiB，不是实测容量。
- Chart 增加 `<release>-ix-exporter`，标签为 `app.kubernetes.io/name=iluvatar-support`、`app.kubernetes.io/component=exporter`，端口名 `metrics`。`iluvatar-ix` 用抓取目标的节点作为设备节点，所以契约指标落在 telemetry Pod 所在的真实节点上。
- Profile Catalog 修订为 `2026-11-23.3`，摘要 `sha256:e7c490c272d24ff671d31c3df57a24b4d34abc99bc92618983bdcacb92cc32df`。天数档案摘要 `sha256:1f201b2f04eb162350d51efda1c6dde36d185e7f14e65c1fbebdbe297dd9c2ba`。Telemetry Catalog 摘要 `sha256:001d944a4171baa4ec0ac9f682621e0876719e22bf14f05f60f7720822762df7`。
- Docker：`ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.5`。Helm Chart：`kasim-runtime` `0.7.5`。已发布的 `0.7.4` 标签保持不变。

# English

## kube-accelerator-sim v0.7.5

v0.7.5 adds a schedulable Iluvatar MRC-V100 physical node.

- `examples/iluvatar-mrc-v100.yaml` projects one node with eight chips on `iluvatar.com/gpu`. The runtime writes `feature.node.cloud.xiaoshiai.cn/accelerator-model.name=mrc-v100`.
- Telemetry follows IX Exporter 4.3.0: `ix_gpu_utilization`, `ix_mem_total`, `ix_mem_used`, `ix_mem_free`, `ix_mem_utilization`, `ix_temperature`, `ix_power_usage`, plus `ix_ecc_sbe_vol_status` and `ix_ecc_dbe_vol_status` at 0 while healthy. The `name` label is the driver name `MRC-V100-0x1B`. Memory stays on the profile default of 32768 MiB and is not a measured capacity.
- The chart publishes `<release>-ix-exporter` with `app.kubernetes.io/name=iluvatar-support`, `app.kubernetes.io/component=exporter`, and port name `metrics`. The `iluvatar-ix` rule uses the scrape target's node, so the canonical series stay on the real node that runs the telemetry Pod.
- The Profile Catalog revision is `2026-11-23.3`, digest `sha256:e7c490c272d24ff671d31c3df57a24b4d34abc99bc92618983bdcacb92cc32df`. The Iluvatar profile digest is `sha256:1f201b2f04eb162350d51efda1c6dde36d185e7f14e65c1fbebdbe297dd9c2ba`. The Telemetry Catalog digest is `sha256:001d944a4171baa4ec0ac9f682621e0876719e22bf14f05f60f7720822762df7`.
- Docker: `ghcr.io/linkmaq/kube-accelerator-sim-controller:0.7.5`. Helm chart: `kasim-runtime` `0.7.5`. The published `0.7.4` tag is unchanged.
