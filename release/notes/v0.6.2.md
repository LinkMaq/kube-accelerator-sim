# 中文

## kube-accelerator-sim v0.6.2

v0.6.2 补全华为昇腾的模拟契约与遥测覆盖，并将全部厂商证据锚定到不可变的
release 版本，NVIDIA DCGM 证据同步修正 NVLink 指标类型。

### 主要变化

- 昇腾节点发现标签：`device-plugin` 契约新增
  `node.kubernetes.io/npu.chip.name` 与 `servertype` 两个 identitySignals，
  各型号携带证据-backed 取值（310 → `310`/`Ascend310-4`，310P →
  `310P`/`Ascend310P-8`，910 → `910A`/`Ascend910-32`，Atlas A2 →
  `910B`/`Ascend910B-20`）；Atlas A3 因无公开证据不声明标签值，不做编造。
- 昇腾 vNPU 预置模板资源：新增 20 个 `huawei.com/Ascend910-*` 与
  `huawei.com/Ascend310P-*` partition 资源（310P 七个、910 十三个），与
  MindCluster `v26.1.0` 预设模板一一对应；`npu-core` 动态 vNPU 保留在
  Ascend910 家族（Atlas A2/A3）。310P 无 AICore 切分路径，不再关联
  `npu-core`。
- 昇腾遥测族扩至 34 个：在原有 9 个核心族上新增 25 个 npu-exporter family
  （整卡/向量使用率、电压、DDR 内存、HBM 温度与带宽利用率、8 个 HBM ECC
  族、网络与链路状态、RoCE 与 PCIe 收发带宽），单位遵循原生约定
  （MB/s、MB/ms）。
- NVIDIA 遥测修正：`DCGM_FI_DEV_NVLINK_BANDWIDTH_TOTAL` 由 counter 修正为
  gauge，跟随 dcgm-exporter 4.6.0–4.8.3（PR #658）对 NVLink 带宽指标的
  上游修正。
- 证据锚点升级：昇腾证据固定到 GitCode `mind-cluster v26.1.0`（与 pinned
  master commit `97641a55` 逐字节比对一致）并补充 B 级 hiascend.com 设备
  规格；两目录 revision 升级为 `2026-09-05.1`，Chart 注解与发布输入同步。
- 运维文档（中英文）新增昇腾发现标签说明、扩展遥测族表与版本锚点表；
  新增示例 `examples/signals/ascend-vnpu-templates.yaml` 覆盖全部 21 个
  可选 vNPU 资源信号。
- Bump product and chart version to 0.6.2。
